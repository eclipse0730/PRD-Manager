# Sample PRD

## 1. 개요

이 문서는 PRD Manager의 샘플 PRD입니다.

## 2. 목적

- PRD를 사람이 보기 쉽게 관리
- Markdown 원본 유지
- 브라우저에서 즉시 수정 및 저장

## 3. 주요 기능

### 3.1 Markdown 미리보기

`prd.md` 파일을 읽어 HTML로 렌더링합니다.

### 3.2 직접 수정

브라우저에서 Markdown을 수정하고 저장하면 원본 `prd.md`에 반영됩니다.

### 3.3 DB Schema 결합

`schemas/db_schema.sql` 파일을 별도 탭에서 확인할 수 있습니다.
