# PRD.md  
## 프로젝트명 (가칭)
# TetraVerse
“꾸미고, 수집하고, 자랑하는 소셜 웹 테트리스”

---

# 1. 프로젝트 개요

## 목표
기존 단순 웹 테트리스가 아닌:

- SNS 기반 간편 접근
- 꾸미기/수집 요소
- 캐릭터 감정 표현
- 배경/테마 시스템
- 실시간 경쟁
- 자랑/공유 기능

을 결합한 차세대 웹 캐주얼 게임 구축.

---

# 2. 핵심 컨셉

## 핵심 방향성

### 1. 접근성
- 설치 없이 웹 즉시 플레이
- 모바일/PC 모두 지원
- SNS 로그인 원클릭 진입

### 2. 꾸미기
- 캐릭터
- 블럭
- 배경
- 이펙트
- 프로필

### 3. 자랑하기
- 최고 점수 카드
- 하이라이트 영상
- 희귀 스킨 자랑
- 랭킹 공유

### 4. 수집 욕구
- 랜덤 뽑기
- 희귀도 시스템
- 시즌 한정 테마

# 19. 핵심 성공 포인트

핵심은:
“잘 만든 테트리스”
보다

“보여주고 싶은 테트리스”

를 만드는 것.

즉:
- 감성
- 꾸미기
- 수집
- 공유
- 짧고 반복 가능한 플레이

가 중요함.
